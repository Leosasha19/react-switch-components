# 🔄 React Switch Components

Интерактивное веб-приложение с тремя переключателями, которые показывают разные данные в зависимости от выбранного режима: генерация случайного числа, отображение текущего времени и обратный отсчёт таймера.

## 🎮 Как работает

1. **Переключатели**
    - **Рандом** — при выборе отображает случайное число
    - **Время** — показывает текущее время в реальном времени
    - **Таймер** — запускает обратный отсчёт с 20 до 0 секунд

2. **Интерактивное управление**
    - Пользователь выбирает один из трёх режимов с помощью кнопок-переключателей
    - Отображаемое значение обновляется в зависимости от выбранного режима
    - Таймер можно запускать заново при повторном выборе

## 🚀 Возможности

- Переключение между тремя режимами отображения данных
- Автоматическое обновление текущего времени каждую секунду
- Обратный отсчёт таймера от 20 до 0 секунд с визуальной индикацией
- Генерация и отображение случайного числа по запросу
- Интуитивный интерфейс с тремя переключателями

## 🛠️ Технологии

**Frontend:**
- React
- TypeScript
- CSS/SCSS

## 🗃️ Архитектура

- Один React-компонент с тремя переключателями для выбора режима
- Использование хуков React для управления состоянием и эффектами (таймеры, обновление времени)
- Простая и расширяемая структура для добавления новых режимов и функций
